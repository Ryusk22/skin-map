角層プロテアーゼの収支 — 落屑・かゆみ・保湿はひとつの天秤で決まる

上の図が「膜から核へ」の縦の話なのに対し、こちらは角層の中で完結する酵素バランスの話。 はがす酵素（KLK）と止める因子（LEKTI）の綱引きが、落屑・炎症・保湿・真皮の4方向に同時に効きます。

真皮ECMの生産ライン — 誰が作り、何が質を決め、何が壊すか

線維芽細胞という1つの職人が、コラーゲン・エラスチン・ヒアルロン酸・デコリンを並行して作っています。 「作る量」だけでなく「質を決める工程」と「壊す側との収支」で最終的な状態が決まります。

皮膚の断面 — 健康な肌と光老化した肌で、同じ場所を見比べる

左右は同じ構造の対比です。基底膜の波打ち・コラーゲンの縄・エラスチンのコイルが、 右ではどう変わるか。マーカー表に出てくる変化を「絵」として持っておくと、論文の組織像の記述が読みやすくなります。

表皮の縦断面 — 分化とバリア脂質は同時に下から上へ進む

細胞は基底層で生まれ、形を変えながら上がって角層になります。 その裏側で、セラミドの生産ラインも同じ方向に流れています。分化マーカーは「今どの階にいるか」の身分証です。

結果から逆引き — 同じ見た目に合流する道

上の経路図は「原因 → 結果」の向きで描いてあるので、同じ結果が離れた場所に複数回出てきます。 このパネルはその逆引きです。臨床で測る数値は1つでも、そこへ至る道は複数ある。 論文や製品が「どの道に効くと言っているか」を見分けるための一覧です。

紅斑（赤み）Mexameter の紅斑指数は1つの数値。でも中身は3種類ある

① 炎症性IL-1・TNF-α → NF-κB → COX-2 / iNOS → PGE2・NO急な赤み・日焼けの赤み。抗炎症でおさまるタイプ
② 血管性VEGF → 血管新生・拡張・透過性亢進消えない赤み・毛細血管拡張・酒さ。血管そのものが増えている
③ 神経性熱・刺激 → TRPV1 → CGRP・サブスタンスP → 血管拡張ヒリつきを伴う赤み。敏感肌タイプ

かゆみ「かゆい」は1つの感覚。でも起こす道は4本ある

① ヒスタミン性肥満細胞 → ヒスタミン → H1受容体蕁麻疹型。抗ヒスタミン薬が効くのは主にここだけ
② 免疫性IL-31 → IL-31RA → JAK1/2 → STAT3 → 知覚神経アトピーの慢性のかゆみ。抗ヒスタミン薬が効きにくい理由
③ プロテアーゼ性KLK・ダニ酵素・トリプターゼ → PAR-2バリアが削られること自体がかゆみ信号になる
④ 神経性TRPV1 → CGRP・サブスタンスP温まるとかゆい・ヒリつくタイプ

色素沈着・シミ「シミが濃い」の中身は、作る・受け取る・血管の3つ

① 産生 ↑α-MSH / ET-1 / SCF → MITF → チロシナーゼ・TRP-1/2メラニン工場の稼働が上がる。美白成分の主戦場
② 受け渡し ↑プロテアーゼ → PAR-2 → メラノソーム取り込み促進作る量が同じでも受け取る量が増えれば濃くなる
③ 血管性VEGF 過剰 → 脆い血管 → 肝斑肝斑が普通の美白で消えにくい背景。トラネキサム酸の文脈

コラーゲン減少（シワ・たるみ）壊す道が4本＋作れなくなる道が1本

① UVUV → ROS → JNK → AP-1 → MMP-1/3/9光老化の王道。抗シワ評価の定番ルート
② 炎症好中球エラスターゼ → デコリン分解 → MMP が刃を入れられる炎症が真皮を壊す順序。カバーが先に剥がされる
③ 汚染PAH → AhR → CYP1A1 → ROS →（①と同じ道へ合流）都市部の肌老化。入口が違うだけで幹線は同じ
④ 老化細胞SASP として MMP・IL-6 を分泌し続ける慢性的にじわじわ削るタイプ。セノリティクスの標的
⑤ 合成低下UV が TGFBR2 を減らす ＋ AP-1 が転写を邪魔する壊れるだけでなく、作る側も止められている

乾燥（水分保持の低下）「乾燥肌」の中身は少なくとも4系統

① NMF不足フィラグリン → カスパーゼ14 → NMF の流れが細るアトピー・加齢。角層が水を抱えられない
② 脂質不足セラミド合成（SPT→CerS）低下・3成分比の崩れモルタル不足。量だけでなく組成が問題のことも
③ TJバリアClaudin-1 / Occludin の緩み角層の下の第2バリアから水が抜ける
④ 免疫による抑制IL-4 / IL-13 → STAT6 がフィラグリン・セラミド合成を止める炎症があるかぎり保湿剤だけでは追いつかない理由

ニキビ詰まり・皮脂・菌・炎症の4段が重なって完成する

① ホルモンアンドロゲン → 5α-R → DHT → AR → 皮脂 ↑皮脂の量を決める土台
② 食事インスリン / IGF-1 → mTORC1 → SREBP-1 → 皮脂 ↑高GI食・乳製品の議論はここ
③ 角化異常毛穴出口の過角化＋皮脂酸化（SQOOH）→ コメドまだ赤くない白・黒ニキビの段階
④ 菌・炎症C. acnes → TLR2 → NLRP3 → IL-1β / IL-17詰まりが赤ニキビに変わる分岐点
